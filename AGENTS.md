# Repository guidance

Read [CLAUDE.md](CLAUDE.md) before making changes; it contains the repository's build,
test, comment, commit, and pull request conventions for every coding agent.
Read any additional `AGENTS.md` in the directories you change.

Run `bash scripts/check-comment-rules.sh` before pushing. Do not grow the comment baseline
to accommodate new violations. Contributor checks and baseline maintenance are described in
[CONTRIBUTING.md](CONTRIBUTING.md).
