kcap page — publish a self-contained HTML page and get a link back, or read one

Usage: kcap page <subcommand>

Subcommands:
  publish <file.html> [options]    Publish a page, print its URL
  list [--mine]                    Pages you can see
  search <query...> [--limit N]    Pages you can see whose title, description
                                   or text match, best first (20 by default).
                                   Words after `--` are searched as they are,
                                   so `search -- --force` finds that flag.
  get <id|url> [--version N]       Print a page's text; --html prints its HTML
  delete <id>                      Remove a page

Options for publish:
  --title <T>                      Name shown in listings and the browser tab.
                                   Defaults to the file's own name.
  --description <D>                One line saying what the page is for.
  --session <id>                   A session this page came out of,
                                   repeatable. Defaults to KCAP_SESSION_ID when
                                   set, so an agent's publish is attributed to
                                   its own session without ceremony.
  --update <pageId>                Publish a new version of an existing
                                   page. The URL does not change, so a link
                                   you already shared stays good. Content and
                                   --session only; a title cannot be changed
                                   after publishing.

SHARING

  A page is private to you until you share it with `kcap sharing`, by the
  object key `publish`, `list`, `get` and `search` print (`publish` and `get`
  on stderr). `list` and `get` show every grant, yours included, as audience
  and relation. See `kcap sharing --help`.

THE PAGE

  A page is served under a sandbox that cannot reach the network, so
  inline every style, script and image as a data URI — an external URL renders
  as nothing. The page must be self-contained HTML.

LIMITS

  A refusal names the limit it hit and the value of that limit, so you never
  have to find the ceiling by bisection.

EXAMPLES

  kcap page publish plan.html --title "Migration plan"
  kcap page publish plan.html --update art_01J9...
  kcap page list --mine
  kcap page search retention numbers
  kcap page get https://kcap.example.com/pages/art_01J9... --html > page.html
