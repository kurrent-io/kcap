kcap disable — Stop recording and delete all session data

Usage: kcap disable [sessionId]

Stops the watcher or the daemon's recorder, which makes no final drain,
prevents future hook events from being sent, and deletes all session
data from the server (streams + read models).

Exits 1 and says why when a send may still reach the server, or when
the daemon did not confirm it stopped. Run it again to delete what lands.

Arguments:
  sessionId               Session ID (defaults to KCAP_SESSION_ID
                          on Claude or CODEX_THREAD_ID on Codex 0.81+)
