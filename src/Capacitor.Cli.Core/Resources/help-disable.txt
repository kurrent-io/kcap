kcap disable — Stop recording and delete all session data

Usage: kcap disable [sessionId]

Stops the watchers and the daemon recorders, which make no final drain,
prevents future hook events from being sent, and deletes all session
data from the server (streams + read models). Every daemon on this
machine is asked.

Exits 1 and says why when something stays unconfirmed: a send may still
land, a daemon or a watcher did not stop or answer, or the data is on
another server. A server it can't reach exits 0 with the data kept; run
it again to delete. A later run asks any daemon an earlier one got no
answer from.

It does not stop a live hosted agent's own output and tools, which keep
reaching the server until the agent ends, or the agent's status and
heartbeat, which carry no session content. The command says when an
agent is running the session.

Arguments:
  sessionId               Session ID (defaults to KCAP_SESSION_ID
                          on Claude or CODEX_THREAD_ID on Codex 0.81+)
