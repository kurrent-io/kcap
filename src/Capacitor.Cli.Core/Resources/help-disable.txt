kcap disable — Stop recording and delete all session data

Usage: kcap disable [sessionId]

Stops the watcher or the daemon's recorder, which makes no final drain,
prevents future hook events from being sent, and deletes all session
data from the server (streams + read models).

Exits 1 and says why when it can't promise the data is gone: a batch
already on its way may still have landed, the daemon did not confirm it
stopped, or the daemon sends to another server. Running it again can't
confirm what an earlier run could not.

While a hosted agent is running the session, its live output keeps
reaching the server until it ends, and the command says so. Stop the
agent to end it.

Arguments:
  sessionId               Session ID (defaults to KCAP_SESSION_ID
                          on Claude or CODEX_THREAD_ID on Codex 0.81+)
